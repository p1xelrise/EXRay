How to start
------------

1. Unzip this folder anywhere (Desktop, a tools folder, a USB stick).
   Nothing is installed.
2. Run @EXE@.
3. Drop an .hdr or .exr file, or a whole folder, onto the window.
   Ctrl+O opens a file, Ctrl+Shift+O a folder. F1 lists every shortcut.

The first time, Windows may show "Windows protected your PC". EXRay
comes from an independent developer and isn't code-signed yet, so
Windows doesn't know it. Click "More info", then "Run anyway".
(Or: right-click the .exe > Properties > tick "Unblock" > OK.)


Free and open source
--------------------

EXRay is free, with every feature and no time limit, for personal use
and for paid client work. Its source code is open (GNU GPL v3) on
GitHub. If it saves you time, you can support it with a payment of your
choice on the download page. It's completely optional.
