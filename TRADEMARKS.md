# EXRay name and logo

The source code of EXRay is free software under the GNU GPL v3 or later (see
[LICENSE](LICENSE)). That license covers the **code**. It does not give
permission to use these:

- the name **“EXRay”** for a software product,
- the **EXRay logo and app icon**,
- the **pixelrise** name and logo.

They identify the official EXRay, made by Giorgos Eleftheroglou (pixelrise),
so that people know which download is the original.

## What's fine

- Talking about EXRay, reviewing it, writing tutorials, showing screenshots,
  and linking to this repository or the download page.
- Sharing **unchanged** official releases (the zip from the Releases page),
  keeping the name and logo as they are.
- Saying that your project is **“based on EXRay”** or **“a fork of EXRay”**.

## What needs a different name and logo

- Any **modified** version you share, sell or publish — a fork, a build with
  your own changes, or a bundle that changes EXRay. Give it its own name and
  icon, and make clear that it is not the official EXRay.

If you're unsure, or want to ask for permission, write to pixelrise@gmail.com.
